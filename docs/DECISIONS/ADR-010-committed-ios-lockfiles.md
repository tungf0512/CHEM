# ADR-010: Committed reproducible iOS dependency locks

## Decision

Commit the Ruby and CocoaPods lockfiles generated by the pinned macOS toolchain. Foundation CI installs them in frozen mode and fails on drift. Intentional refreshes use the manual `ios-lockfile-refresh` workflow, which commits only those two files.

## Rationale

Regenerating dependency metadata during every build made a green runner dependent on an artifact that could not be reproduced from source. Committed resolution makes simulator/native CI and signed release input auditable and repeatable without hand-authored lock contents.

## Consequences

Dependency changes require a macOS refresh and a follow-up green foundation run. `Pods/`, Codegen output, and build products remain generated and ignored.
